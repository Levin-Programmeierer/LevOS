# LevOS

LevOS is a **personal operating system project built from scratch to learn how operating systems work**.

The project is mainly an experiment and learning experience. I'm building the different parts of the system myself to better understand low-level programming, computer architecture, and operating-system development.

## What I'm Learning

The project currently explores things such as:

* x86 assembly and C
* Booting and kernel initialization
* GDT and IDT
* Interrupts and exceptions
* Memory management
* Paging
* Processes
* Ring 3 / user-mode execution
* System calls
* Keyboard and timer drivers
* Shell development

More features will be added as I continue learning.

## Status

LevOS is **not intended to be a production operating system**. It is a personal project that is constantly changing as I experiment with new concepts and learn more about OS development.

Things may break, change, or be completely rewritten.

## Building

The project currently targets **32-bit x86** and is developed using C, x86 assembly, GCC, GNU Binutils, Make, and QEMU.

To build:

```bash
make
```

The project is primarily tested in QEMU.
